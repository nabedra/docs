Nabedra Database is a Rust server with an HTTP API and a synchronous Python ORM. Its OLAP build stores immutable Parquet snapshots, while its experimental OLTP build stores indexed rows on a local RocksDB volume. Nabedra Events is a separate broker for partitioned event logs and subscription checkpoints.

## Choose a database engine

| Engine | Where data lives | Start here |
| --- | --- | --- |
| OLAP | Immutable Parquet objects and a conditionally updated catalog in S3 | [OLAP storage and queries](/server/olap) |
| OLTP | RocksDB pools on mounted filesystems, with an experimental local single-replica mode | [Run local OLTP](/server/oltp) |

Each server binary has one engine. The same Python table and query methods work with both. To move a database between them, use the [offline export and import commands](/operations/backup-and-migration).

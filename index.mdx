Nabedra Database serves OLAP and OLTP queries over HTTP. Use the synchronous Python ORM or the asynchronous TypeScript ORM to work with either database engine.

Follow [Installation](/guides/installation) to get the latest published packages or download the source archive for preview features.

## Choose a database engine

| Engine | Use it for | Start here |
| --- | --- | --- |
| OLAP | Analytical scans over immutable Parquet snapshots in S3 | [OLAP storage and queries](/server/olap) |
| OLTP (source preview) | Indexed reads, writes, and transactions on RocksDB | [Run local OLTP](/server/oltp) |

Each database binary selects one engine at build time. To move OLAP tables to OLTP, use the [offline export and import commands](/operations/backup-and-migration#move-olap-tables-to-oltp).
